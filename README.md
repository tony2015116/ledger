# 行为规划 · 安装版（原「时间账本」）

按「模式」（通勤日、下场模式、休假日）排好每天的固定安排，再把习惯和临时安排拖进当天的时间轴。

和「每日打卡记录」一样的方式发布：放到 GitHub Pages，用 Chrome 或 Edge 安装为应用。

**数据不会上传。** 仓库里只有页面代码，数据只写在你自己电脑的数据文件夹里。

## 发布（约 5 分钟）

1. 在 GitHub 新建一个仓库，比如叫 `ledger`（和打卡记录的 `tracker` 仓库放在**同一个 GitHub 账号**下）。
   - 免费账号的 GitHub Pages 需要公开仓库，公开的只是页面代码。
2. 点 **Add file → Upload files**，把这几个文件拖进去，点 **Commit changes**：
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. 进入 **Settings → Pages**，选 **Deploy from a branch**，分支 `main`，目录 `/ (root)`，保存。
4. 等 1～2 分钟，网址形如 `https://你的用户名.github.io/ledger/`。
5. 用 Edge 打开，点页面右上角的 **「📲 安装为应用」**，或者 **… → 应用 → 将此站点作为应用安装**。
6. 从开始菜单打开「行为规划」，进入 **设置 → 数据存储 → 选择数据文件夹**，**选和打卡记录相同的那个文件夹**。

## 和每日打卡记录联动

两个应用在同一个 GitHub 账号下（`你的用户名.github.io/tracker/` 和 `你的用户名.github.io/ledger/`），属于同一个网站，所以会自动联动，不用手动导入：

- 在打卡记录里打卡保存后，行为规划几乎立刻就能收到（两个窗口同时开着也行）。
- 同时，行为规划也会读取数据文件夹里的 `打卡数据.json`，每 15 秒检查一次，切回窗口时立即检查。
- 行为规划只读取打卡数据，不会修改它。
- **习惯以打卡记录为准**：在打卡记录里新增、改名或停用习惯，这里会自动跟着变。想给习惯留时间，在「今天」页点一下或拖进时间轴即可。

数据文件夹里会是这样：

```
打卡记录/
├─ 打卡数据.json        ← 每日打卡记录写入
├─ 时间账本.json        ← 行为规划写入（沿用旧文件名，已有数据不受影响）
└─ 历史备份/            ← 两个应用每天各自备份一份，保留 60 天
```

## 把 Claude 里的数据搬过来

在 claude.ai 里的网页版打开 **设置 → 数据存储 → 导出数据**，得到一个 `.json` 文件；
在安装好的应用里点 **从备份导入**，选这个文件即可。

## 以后更新

用新文件替换仓库里的 `index.html`。已安装的应用联网打开时会自动用上新版本。

## 在 iPad 上使用

1. 用 Safari 打开 `https://你的用户名.github.io/ledger/`，点分享按钮，选「添加到主屏幕」。
2. iPad 上的 Safari 不能直接写入本地文件夹，数据保存在 iPad 的浏览器里。请定期在 **设置 → 数据存储 → 导出数据**，存到「文件」或 iCloud 云盘。
3. 关于打卡联动：
   - 两个应用都在 Safari 标签页里打开时，属于同一个网站，会自动联动。
   - 分别「添加到主屏幕」后，iPad 会把它们的数据隔开，不能自动联动。这时在打卡记录里导出 .json，再到 **设置 → 关联每日打卡记录** 里选择这个文件。
4. 在时间轴上：点一下标签就会放进下一个空档；想放到指定时间，长按一下再拖。
